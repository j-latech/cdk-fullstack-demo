
# AWS CDK Fullstack Demo 1

## TypeScript AWS CDK Full‑Stack Demo

## Objective

### The aim of this project

The aim of this project is to set up a local AWS cloud environment using AWS CDK, AWS SDK, and MiniStacks (https://ministack.org/).  
MiniStacks is a Docker container that emulates an AWS cloud environment locally.  

This repository will serve as the foundational blueprint for future projects and is the first in a series of upcoming full‑stack demonstrations.
